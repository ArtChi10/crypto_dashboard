Как читать историю запусков

Каждый run - одна попытка pipeline. Новые рабочие запуски создаются через Binance page, CSV upload или CLI.

  • created - metadata record exists, но pipeline не запускался. Такие старые записи могли остаться до упрощения Dashboard.
  • running - pipeline сейчас выполняется.
  • success - artifacts, metrics и reports созданы.
  • failed - ошибка сохранена в error_message.
